# 🖼️ PROMPTS DE GÉNÉRATION D'IMAGES — Style Pixar / Disney 3D

> 24 prompts, **un par personnage**, tous différents. À utiliser avec
> Midjourney, DALL·E, Sora, Leonardo, etc. Les prompts sont en **anglais**
> (meilleur rendu sur les générateurs) ; une note FR accompagne chaque famille.

---

## ⚙️ Base technique commune (à coller à la fin de CHAQUE prompt)

Pour que les 24 cartes soient homogènes (même style, même cadrage), ajoute
toujours ce **suffixe** :

```
, 3D Disney Pixar style, exaggerated cartoon proportions, big expressive eyes,
soft subsurface skin, cinematic studio lighting, vibrant saturated colors,
3/4 body shot facing camera, clean simple background, vertical card composition,
ultra detailed, high quality render, octane render --ar 3:4
```

> 💡 **Astuce cohérence** : génère toujours avec le même outil et, si possible, la
> même *seed* / référence de style pour que les 24 personnages aient l'air de
> sortir du même film.
