# ⚡ PROMPTS — CARTES ACTION & ÉVÉNEMENT (format réduit)

> Cartes **neutres** (pas de famille) → cadre **gris kraft** avec bandeau **rouge
> « ACTION »** (ou orange **« ÉVÉNEMENT »**). **Format plus petit** que les cartes
> personnage : **carré compact**, illustration de la scène (pas de portrait), titre
> + effet. Même style 3D Disney Pixar.

## ⚙️ Base commune
- **Petite carte carrée** (ratio 1:1), style 3D Disney Pixar.
- Cadre gris kraft/carton, bandeau rouge en haut avec le mot **ACTION** (ou orange
  **ÉVÉNEMENT**).
- Titre en gras + **petite illustration de scène** + encadré **« EFFET : … »**.
- Texte français net, tout reste dans le cadre. `--ar 1:1`
